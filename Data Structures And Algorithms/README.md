Queue Data Structure in C

This folder contains two Queue implementations using the C programming language.

1. Linear Queue (Queue1.c)

Implements a Linear Queue using an array.

Supports Enqueue (Insertion), Dequeue (Deletion), and Display operations.

Follows the FIFO (First In, First Out) principle.

2. Circular Queue (Queue2.c)

Implements a Circular Queue using an array.

Supports Enqueue (Insertion), Dequeue (Deletion), and Display operations.

Uses the modulo (%) operator for circular movement.

Reuses empty spaces created after deletion.
